# Open sourcing stuff is uncomfortable

I've been jamming on two new open source projects: [Dump](https://dump.page/) and [Hoo](https://www.get-hoo.com/).

The process of open-sourcing is weird. Uncomfortable is the word I'd use.

Not because I think the idea is super secretive - but because of the feeling of vulnerability, and loss of control. Opening up *my* code to the outside world.

The paradox, though? I barely wrote any of the code.

Ideas are cheap. Tokens are kinda cheap. And if you can point Claude at some unit tests and recreate the code anyway - why *not* open source something?

Out of curiosity, I asked Claude for its opinion:

> Overall: the codebase is clean, well-structured, and already prepped. If you're willing to put in some maintenance effort, I'd say go for it. What's your main hesitation?

So, since the main hesitation seems to be self-doubt, I present to you:

 - [Dump](https://github.com/Vochsel/dump.page) - a visual board tool for organizing notes, links, and checklists into shared, collaborative spaces.
 - [Hoo](https://github.com/Vochsel/hoo) - a graph-based web browser where every tab is a node, built for running AI agents that automate browser tasks reliably and repeatably.

\- Ben
